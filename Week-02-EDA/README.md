# DecodeLabs Project 2 — Exploratory Data Analysis (EDA)

## Project Overview

This project explores an e-commerce dataset using Microsoft Excel to uncover business insights through Exploratory Data Analysis (EDA).

## Objectives
- Explore the structure and quality of the dataset.
- Analyze distributions of key variables.
- Identify sales trends over time.
- Examine relationships between business variables.
- Detect potential outliers.
- Build an interactive EDA dashboard.


## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Histograms

## Dataset Information

- **Dataset:** E-Commerce Sales Dataset
- **Total Records:** 1,200
- **Time Period:** January 2023 – June 2025

## EDA Sections

- Distribution Analysis
- Trend Analysis
- Relationship Analysis
- Outlier Detection
- Executive Summary
- Interactive Dashboard

## Dashboard Highlights

- Distribution Analysis
- Trend Analysis
- Relationship Analysis
- Key Business Insights
- Interactive Filters

## Key Findings

- Credit Card was the highest revenue payment method.
- Chair generated the highest product revenue.
- Instagram generated the highest revenue among referral sources.
- Cancelled orders contributed the highest total order value.
- Customers purchasing 5–6 items generated the most revenue.
- No significant outliers were detected using the IQR method.
