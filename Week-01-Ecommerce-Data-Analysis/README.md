# Week 1: E-commerce Data Analysis

## Project Overview

This project focuses on analyzing an e-commerce dataset using Microsoft Excel. The objective was to clean the data, perform exploratory analysis, calculate key performance indicators (KPIs), create PivotTables and charts, and build an interactive dashboard to provide business insights.

---

## Objectives
- Clean and prepare the dataset for analysis.
- Analyze sales performance and customer purchasing behavior.
- Identify top-performing products and payment methods.
- Build an interactive Excel dashboard for business reporting.
- Generate actionable business insights
---

## Tools Used

- Microsoft Excel
- PivotTables
- Pivot Charts
- Slicers
- Dashboard Design

## Dataset Information

- **Dataset:** E-Commerce Sales Dataset
- **Total Records:** 1,200
- **Time Period:** January 2023 – June 2025
---
## Dashboard Features

- Revenue Overview
- Total Orders
- Average Order Value
- Sales by Product
- Sales by Payment Method
- Monthly Revenue Trend
- Monthly Order Trend
- Interactive Slicers

## Key Insights
- June 2024 generated the highest monthly revenue.
- Chair produced the highest revenue and the highest quantity sold.
- Online payment was the most preferred payment method.
- FREESHIP was the most frequently used coupon.
- Cancelled orders slightly exceeded other order statuses, indicating an opportunity to improve order fulfillment.
- Credit Card generated the highest revenue.
- Instagram produced the highest sales among referral sources.
- Larger cart sizes generally generated more revenue.
- Revenue fluctuated across months, with several noticeable peaks.
